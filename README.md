# Resolução de Atividades - Lógica de Programação com Python

Este repositório contém a entrega das atividades de lógica de programação desenvolvidas em Python. O projeto foi estruturado seguindo boas práticas de desenvolvimento, priorizando a organização, nomenclatura clara de variáveis e eficiência algorítmica.

---

## Ferramentas Utilizadas
* **Ambiente de Desenvolvimento:** Google Colab.
* **Linguagem:** Python 3.x.

---

## Descrição das Atividades

Cada script foi desenvolvido para resolver um problema específico, conforme mostrado abaixo:

1.  **`ex01_pares_impares.py`**: Algoritmo que utiliza o laço `for` para iterar de 0 a 100, identificando e exibindo números pares e ímpares através do operador de módulo (`%`).
2.  **`ex02_maior_menor.py`**: Script que realiza a leitura de três números, armazena-os em uma **lista** e utiliza funções nativas para identificar o maior e o menor valor.
3.  **`ex03_nome_escada.py`**: Manipulação de strings para exibir um nome digitado no formato de escada vertical, utilizando conceitos de fatiamento (slicing).
4.  **`ex04_fibonacci.py`**: Gerador da sequência de Fibonacci até o n-ésimo termo definido pelo usuário, aplicando lógica de somatório de termos anteriores.
5.  **`ex05_validacao_dados.py`**: Programa de validação que utiliza laços `while` e condicionais compostas para garantir que as entradas (nome, idade, salário, sexo e estado civil) sigam regras específicas.
6.  **`ex06_numero_primo.py`**: Algoritmo que determina se um número inteiro é primo através da verificação de divisores, utilizando o operador `%`.
7.  **`ex07_fatorial.py`**: Cálculo do fatorial de um número utilizando o laço de repetição `for`.
8.  **`ex08_analise_lista.py`**: Operações completas sobre uma lista numérica: tamanho, maior/menor valor, soma total e ordenação (crescente e decrescente).
9.  **`ex09_dicionario_tabela.py`**: Representação de dados tabulares utilizando a estrutura de **Dicionário** do Python, garantindo a correta relação entre chaves e valores.
10. **`ex10_validacao_senha.py`**: Sistema de controle de acesso que utiliza o laço `while` para validar a senha numérica "676767".
11. **`ex11_tabuada.py`**: Gerador de tabuada dinâmica (1 a 10) com base na entrada do usuário.



## Critérios Técnicos Aplicados (Clean Code)

 o código foi desenvolvido focando em:
* **Nomenclatura Descritiva:** Variáveis e funções nomeadas conforme sua finalidade (ex: `valor_salario`, `lista_numeros`).
* **Sequência Lógica:** Algoritmos estruturados com início, meio e fim bem definidos, evitando redundâncias.
* **Tipagem Adequada:** Uso correto de `int`, `float`, `str` e estruturas de dados como `list` e `dict`.
* **Indentação:** Código organizado para facilitar a leitura e manutenção.
